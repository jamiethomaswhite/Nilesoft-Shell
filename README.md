<br />
A Nilesoft Shell setup for a super simple and basic, sanely organised (mostly) default Windows context menu.<br />
<br />
<br />
Hopefully, in future, it should also provide extensibility to add your own custom snippets and maintain some kind of order in the chaos. This is still WIP though.<br />
<br />
<br />
Thanks to moudey for creating Shell, which is an absolute godsend. Shell must be installed to use this setup, but it is as simple as an in-place copy and paste to switch to my setup.<br />
https://nilesoft.org/<br />
https://github.com/moudey/Shell<br />
and masive kudos to Rubic for all the useful snippets and support that got us here!<br />
https://github.com/RubicBG/Nilesoft-Shell-Snippets/<br />
