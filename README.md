A Nilesoft Shell setup for a simple, reorganised and efficient context menu, that should also provide extensibility to add your own custom snippets and maintain some kind of order!

Thanks to moudey for creating Shell<br />
https://nilesoft.org/<br />
https://github.com/moudey/Shell<br />
and RubicBG for all the useful snippets and support<br />
https://github.com/RubicBG/Nilesoft-Shell-Snippets/<br />
