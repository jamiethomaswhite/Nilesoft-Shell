A Nilesoft Shell setup for a super simple and basic, sanely organised (mostly) default Windows context menu.<br />
<br />
Shell must be installed to use this setup, but it is as simple as an in-place copy and paste to switch to my setup.
<br />
Hopefully, in future, this will also provide extensibility, to add your own custom snippets and still maintain some kind of order in the chaos. This is still WIP though, and many entries have formed a resistance against the empire.<br />
<br />
Thanks to moudey for creating Shell, which is an absolute godsend.<br />
https://nilesoft.org/<br />

and massive kudos to Rubic for all the useful snippets and support that got us here!<br />
